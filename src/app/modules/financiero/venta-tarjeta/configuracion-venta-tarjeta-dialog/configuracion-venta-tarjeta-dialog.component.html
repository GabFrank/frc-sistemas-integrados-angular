Habilitar venta con tarjeta
Cuando está activado, las sucursales podrán registrar ventas con tarjeta escaneando la terminal POS desde el desktop y confirmando el registro desde la aplicación móvil. Si está desactivado, el cobro con tarjeta funciona como un medio de pago normal, sin el escaneo de terminal ni el registro adicional.
